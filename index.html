What broke, and how I fixed it

ProblemA failed save made the posting job repeat the same post every hour.

FixEvery action now has a saved "done" record and a duplicate check before it runs, plus a cleanup tool that removed the copies.

ProblemA scheduled job sometimes didn't start, so posts went out late.

FixA dispatcher starts each run, confirms it really started, and retries up to three times.

ProblemAn email provider blocked sending one morning.

FixThe agent saves drafts instead, puts a reminder in the calendar, and sends them on the next run.
